# win8 — автоматизация установки Windows 8.1 в bhyve (FreeBSD)

Набор скриптов для полностью автоматической сборки кастомного установочного
ISO Windows 8.1, его запуска в виртуальной машине **bhyve** на FreeBSD и
последующей настройки гостевой системы «под себя»: удалённый доступ,
портативный софт, автологин, RemoteApp и т.д.

Общий сценарий использования:

1. На хосте FreeBSD берётся оригинальный ISO Windows 8.1 и модифицируется
   (`install.sh`) — в образ добавляются файлы ответов, драйверы, скрипт
   автоустановки, отключается запрос «Press any key to boot from CD».
2. Полученный ISO подключается к виртуальной машине bhyve, которая
   запускается скриптом `run_win8.sh` (первый прогон — установка) или
   `install.sh` (единый цикл «установил → отключил ISO → работает»).
3. Внутри Windows автоматически (через `autounattend.xml` → `setup.bat` →
   `install.cmd`) разворачивается образ, ставятся драйверы, копируется
   портативный софт, настраивается сеть, RDP, автологин и ярлыки на рабочем
   столе.
4. Управление и выключение машины делается удалённо с другого хоста через
   `off_win.sh`.

> ⚠️ Скрипты писались под конкретную домашнюю инфраструктуру (IP-адреса,
> пользователь `vcore`, пароли, пути `/ntfs-2TB/...`, `D:\app\...` и т.д.).
> Перед использованием на своей машине их нужно адаптировать под себя.

## Структура и назначение файлов

### Скрипты хоста (FreeBSD, sh)

| Файл | Назначение |
|---|---|
| **`install.sh`** | Главный скрипт подготовки и первого запуска ВМ. Проверяет наличие пакетов FreeBSD (`7-zip`, `wimlib`, `cdrtools`), распаковывает оригинальный ISO Windows 8.1 через `7z`, копирует в него файлы автоустановки (`autounattend.xml`, `install.cmd`, `setup.bat` и др.), подменяет `efisys.bin` на версию без запроса нажатия клавиши, патчит `boot.wim`/`install.wim` через `wimlib-imagex`/`wimupdate` (добавляет `winpeshl.ini`, удаляет ненужные компоненты по списку `remove_recovery.txt`), собирает новый загрузочный ISO (`mkisofs`), создаёт диск ВМ (`truncate`) и в цикле запускает `bhyve` (с опциональным пробросом Intel GPU по аргументу `gpu`), пересоздавая ВМ при перезагрузках Windows до появления флага `installed.flag`. |
| **`run_win8.sh`** | Повседневный запуск уже установленной ВМ `win8` через `bhyve`. Поддерживает ключи `gpu` (проброс встроенной Intel-графики) и `usb` (проброс USB-контроллера), настраивает framebuffer/VNC на порту 5900, диск с приложениями (`app8.1.img`), сеть через `tap0`, звук через `/dev/dsp`. При падении ВМ уничтожает её (`bhyvectl --destroy`) и перезапускает в цикле. |
| **`off_win.sh`** | Скрипт удалённого выключения. Через SSH заходит на хост с bhyve, кладёт и запускает там временный скрипт: посылает Windows команду `shutdown` через `atexec.py` (Impacket), дожидается остановки процесса `bhyve`, затем освобождает проброшенные PCI-устройства (GPU, USB-контроллеры) обратно ядру FreeBSD. |
| **`mount-app.img.sh`** | Утилита для подключения NTFS-образа диска приложений (`app8.1.img`) с хоста FreeBSD: создаёт `md`-устройство (`mdconfig`), чинит и монтирует NTFS-раздел через `ntfs-3g`/`ntfsfix` в `/mnt/app`, выводит команды для последующего размонтирования. |
| **`win8_iso_copy.sh`** | Разовый вспомогательный скрипт: распаковывает оригинальный образ Windows 8.1 (Embedded Industry, RU) из `7z`-архива в рабочую папку. |
| **`grep.sh`** | Ищет в `install.wim` (через `wimdir`) все каталоги/манифесты `x86_*` в `WinSxS` и формирует из них команды `delete --recursive '...'`, пригодные для вставки в файл-скрипт `wimupdate`/`remove_recovery.txt` — используется для чистки образа от x86-компонентов на x64-системе. |
| **`clean_graphics.sh`** | POSIX-sh скрипт очистки папки с драйвером Intel Graphics (`igdlh64.inf`) от файлов, не нужных после урезания `.inf` (Control Panel/трей, Vulkan, OpenCL, WiDi/Miracast, кодеки Media SDK, HDCP/HECI-службы и т.п.). По умолчанию dry-run (только показывает, что будет удалено), реальное удаление — с ключом `-d`. |

### Скрипты и файлы для гостевой Windows

| Файл | Назначение |
|---|---|
| **`autounattend.xml`** | Файл ответов Windows Setup (unattend). Задаёт автоматическую разметку/установку без диалогов, имя компьютера `VCORE-PC`, часовой пояс `Russian Standard Time`, PID/ключ продукта (см. `PID.txt`) и запускает синхронные команды на этапе установки. |
| **`ei.cfg`** | Указывает установщику Windows, какую редакцию/канал ставить без запроса выбора: `Professional`, `Retail`. |
| **`PID.txt`** | Ключ продукта (Product ID) для автоматического ввода при установке. |
| **`winpeshl.ini`** | Конфигурация Windows PE — при загрузке в PE сразу запускает `D:\setup.bat` вместо стандартной оболочки установки. Интегрируется в `boot.wim` скриптом `install.sh`. |
| **`setup.bat`** | Скрипт, который выполняется прямо из среды WinPE (см. `winpeshl.ini`). Через `diskpart` создаёт GPT-разметку (EFI-раздел + системный NTFS), ищет `install.wim`/`install.esd` на всех буквах дисков, разворачивает образ через `dism /apply-image` (с фолбэком на `gimagex`), копирует `LayoutModification.xml`, `autounattend.xml` (как `unattend.xml` в `C:\Windows\Panther`), набор скриптов (`install.cmd`, `firefox.ps1`, `autologin.cmd`, `off_win.sh` и др.) и папки с приложениями/драйверами (`app`, `NVIDIA`, `NetKVM`) на диск `C:`, после чего настраивает загрузчик (`bcdboot`). |
| **`install.cmd`** | Основной скрипт постустановочной настройки Windows (запускается уже из установленной системы, с правами администратора). Устанавливает драйверы графики/сети (`pnputil`), VB-Cable и Open-Shell; настраивает PowerShell-профиль; включает сетевое обнаружение и общий доступ к файлам/принтерам, гостевой SMB-доступ без пароля; монтирует сетевой диск `Z:`; отключает UAC-фильтр для сетевых подключений и брандмауэр; включает автологин пользователя `vcore`; отключает Windows Store; включает и настраивает RDP (в т.ч. RemoteApp для Блокнота, SDRSharp, Firefox Portable, O&O ShutUp10); создаёт ярлыки на рабочем столе для портативных программ (Firefox, Mypal, Proxifier, Supermium, RetroBar, AVZ, SDRSharp, DSDPlus, TelegramDesktop, Midnight Commander и др.) и добавляет автозапуск Firefox Portable в `Startup`. |
| **`autologin.cmd`** | Отдельный (упрощённый) скрипт включения автологина Windows под пользователем `vcore` и подключения сетевого диска `Z:` — по сути вырезка соответствующей части `install.cmd` для повторного использования. |
| **`firefox.ps1`** | PowerShell-скрипт восстановления профиля Firefox Portable: удаляет старый профиль, распаковывает `profile.tar.xz`/`profile.tar` и копирует его на место штатного профиля браузера. |
| **`clean_graphics.ps1`** | PowerShell-аналог `clean_graphics.sh` — чистит папку драйвера Intel Graphics от лишних файлов после урезания `.inf` (по умолчанию dry-run, реальное удаление — ключ `-Delete`). |
| **`Microsoft.PowerShell_profile.ps1`** | Профиль PowerShell, который копируется в `Documents\WindowsPowerShell` пользователя. Добавляет в `PATH` текущей сессии пути к портативным программам: PortableGit, OpenSSL, 7-Zip, mpv, yt-dlp, Streamlink, FreeTube. |
| **`remove_recovery.txt`** | Список команд для `wimupdate`/`wimlib-imagex update` — удаляет из образа Windows (`install.wim`) раздел восстановления, экран блокировки, Windows Store (`WindowsApps`), Internet Explorer, Windows Defender, лог-файлы, Windows Media Player, почту Windows и т.п., уменьшая итоговый образ. |
| **`efisys_noprompt.bin`** | Бинарный загрузочный сектор EFI (`FAT12`, метка `EFISECTOR`) для замены штатного `efi/microsoft/boot/efisys.bin` в ISO — убирает надпись «Press any key to boot from CD or DVD…» при загрузке установщика. |
| **`note`** | Заметка-памятка с готовой командой `oscdimg` для сборки загрузочного ISO (альтернатива используемым в `install.sh` `mkisofs`). |

## Требования

- FreeBSD-хост с настроенным **bhyve**, `doas`, `tap`-интерфейсом.
- Пакеты: `archivers/7-zip`, `sysutils/wimlib`, `sysutils/cdrtools` (и `ntfs-3g`
  для `mount-app.img.sh`).
- Оригинальный дистрибутив Windows 8.1 (x64, Russian) в виде ISO.
- Собственные версии портативных программ, драйверов NVIDIA/NetKVM и файла
  `LayoutModification.xml` (в репозитории отсутствуют, ожидаются рядом со
  скриптами по путям, зашитым в `install.sh`/`setup.bat`).

## Быстрый старт

```sh
# на FreeBSD-хосте
./install.sh          # подготовка ISO и первичная установка Windows
./install.sh gpu       # то же самое, но с пробросом Intel GPU

# после установки, повседневный запуск
./run_win8.sh
./run_win8.sh gpu usb  # с пробросом GPU и USB

# удалённое выключение ВМ (с другого хоста)
./off_win.sh
```

## Дисклеймер

Скрипты содержат учётные данные и пароли для локальной домашней сети
(автологин, `atexec.py`), захардкоженные IP-адреса и пути. Перед публикацией
или использованием в чужом окружении обязательно замените эти значения на
свои и не публикуйте реальные пароли/ключи продукта.
